# Generador de Certificados DOCX

App en Streamlit para generar certificados masivos a partir de un Excel y una plantilla Word (.docx).

## 🚀 Funcionalidades

- Subida de archivo Excel
- Subida de plantilla DOCX
- Vista previa de datos
- Generación masiva de documentos
- Descarga en ZIP

## ▶️ Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
``
